# M5Burner listing (copy/paste)

**Name:** CapDeck
**Device:** Cardputer (ADV)
**Version:** 1.1.0
**Firmware file:** `firmware/CapDeck-v1.1.0-full-0x0.bin` (full image, flash at 0x0)
**Cover image:** `screenshots/theme_cyber.png` or `screenshots/main_menu.png`

**Description:**
CapDeck turns the Cardputer ADV into a pocket control deck. It has a Bruce-style icon menu with 10 apps:
Home Assistant (buttons + push-to-talk voice), Local AI chat (llama.cpp / Ollama / LM Studio),
LoRa chat and a 902-928 MHz scanner, a Meshtastic node map with GPS (Cap LoRa-1262, receive-only),
Flipper .ir remotes, 433 MHz decoder, and a phone control-panel hotspot to set it up without removing the SD card.
Built-in themes: Default, Cyber, Matrix, Amber.
Source, changelog and docs: https://github.com/doot-noot/Capdeck

Note for M5Launcher users: install sd_card/CapDeck.bin from the SD card instead to keep your launcher.
